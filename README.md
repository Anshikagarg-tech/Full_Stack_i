# 🌐 HTML & CSS Practice

A collection of simple and creative web pages built using **HTML and CSS** to practice different web development concepts.

## 📂 Tasks

| #  | Task                 | Concepts Used                                        |
| -- | -------------------- | ---------------------------------------------------- |
| 01 | 🔐 Login Page        | Forms, Input fields, Buttons, CSS styling            |
| 02 | 🧭 Navigation Bar    | Navigation, Links, Hover effects, Flexbox            |
| 03 | 📰 Newspaper Layout  | Columns, Typography, Borders, Layout                 |
| 04 | 📝 Registration Form | Forms, Input, Radio buttons, Select, Textarea        |
| 05 | 🌄 Background Image  | Background image, Size, Position, Repeat, Attachment |

## ✨ Highlights

### 🔐 Login Page

A simple login interface with email and password fields.

### 🧭 Navigation Bar

A basic navigation bar with links and hover effects.

### 📰 Newspaper Layout

A newspaper-style webpage using columns, headings, borders and typography.

### 📝 Registration Form

A registration form containing different HTML form elements such as text fields, radio buttons, dropdowns and a textarea.

### 🌄 Background Image

A webpage demonstrating CSS background properties including:

```css
background-image
background-size
background-position
background-repeat
background-attachment
```

3. Open any task folder.

4. Open `index.html` in your browser.
